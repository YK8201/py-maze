# 第7章 1手戻す：動く前の迷路を「コピーして」記録しておく

R キーのやり直しは、最初からになってしまいます。最後の1手だけを取り消せたら、じっくり考えるパズルとしてずっと遊びやすくなります。この章では Z キーで1手前に戻れるようにします。いわゆる **UNDO（アンドゥ）** です。

## 考え方：動く前のようすを積み重ねておく

1手動く前に、そのときのようす（迷路・プレイヤーの位置・手数）をリストに記録しておきます。Z キーが押されたら、リストの最後の記録を取り出して、その状態に戻します。何回も戻れるように、記録は1手ごとに積み重ねていきます。

まず `load_level` の最後に、記録用の空のリストを作る1行を足します。

```python
        self.history = []  # 1手ごとの記録（UNDO用）
```

次に、`move` で手数を増やす直前に記録を足します。

```python
    def move(self, dx, dy):
        if self.clear:
            return
        if self.is_wall(self.x + dx, self.y + dy):
            return  # 1マスも動けないときは手数にかぞえない
        # 動く前のようすを記録しておく（迷路はコピーしてから）
        grid_copy = [row[:] for row in self.grid]
        self.history.append((grid_copy, self.x, self.y, self.moves))
        self.moves += 1
        while not self.is_wall(self.x + dx, self.y + dy):
            self.x += dx
            self.y += dy
            tile = self.grid[self.y][self.x]
            if tile == ".":
                self.grid[self.y][self.x] = " "
            if tile == "E" and self.count_dots() == 0:
                self.clear = True
                break
```

記録は `(grid_copy, self.x, self.y, self.moves)` のように4つの値を `( )` でまとめた形にしています。これを **タプル** と呼びます。リストと似ていますが、あとから中身を変えられません。記録はあとで書きかえるものではないので、タプルがちょうどよい入れ物です。

## 戻す処理

`undo` メソッドを新しく作ります。`update` の上あたりに書いてください。

```python
    def undo(self):
        if len(self.history) == 0:
            return
        grid, x, y, moves = self.history.pop()  # 最後の記録を取り出す
        self.grid = grid
        self.x = x
        self.y = y
        self.moves = moves
        self.clear = False
```

`pop()` は、リストの最後の要素を取り出して、リストからは消す命令です。最後に記録したものが最初に出てくるので、新しい手から順に戻せます。

取り出したタプルは `grid, x, y, moves = ...` のように、4つの変数に一度に分けて受け取れます。

最後に `update` に Z キーの判定を足し、操作の説明を `"ARROWS:MOVE Z:UNDO R:RESET"` に書きかえれば完成です。完成コードは `code/step07/main.py` にあります。

## なぜ「コピー」が必要なのか

`move` の中の次の行が、この章でいちばん大事なところです。

```python
grid_copy = [row[:] for row in self.grid]
```

ためしに、この行を次のように変えて実行してみてください。

```python
grid_copy = self.grid
```

ドットを拾ってから Z キーで戻ると、プレイヤーの位置は戻るのに、拾ったドットが戻ってきません。

原因は、Python のリストの性質にあります。`grid_copy = self.grid` は、リストを複製しているわけではありません。同じリストに、もう1つ名前を付けているだけです。そのあとドットを拾って `self.grid` を書きかえると、`grid_copy` から見ても書きかわっています。

Python の対話モード（ターミナルで `python` とだけ打つと始まる）で確かめられます。

```python
>>> a = [[1, 2], [3, 4]]
>>> b = a
>>> b[0][0] = 99
>>> a
[[99, 2], [3, 4]]
```

`b` を書きかえたのに `a` も変わりました。別々のリストにするには、コピーを作る必要があります。`row[:]` は「`row` の最初から最後までを切り出した新しいリスト」で、つまり1行ぶんのコピーです。

```python
>>> a = [[1, 2], [3, 4]]
>>> b = [row[:] for row in a]
>>> b[0][0] = 99
>>> a
[[1, 2], [3, 4]]
```

今度は `a` が変わっていません。

`self.grid[:]` のように外側のリストだけをコピーしても、うまくいきません。外側のリストは新しくなりますが、中に入っている各行のリストは元と同じものだからです。迷路はリストのリストなので、1行ずつコピーする必要があります。

この「同じリストに別の名前が付いているだけ」という性質は、Python でよくつまずくところです。ゲームに限らず、リストを記録しておきたいときは、コピーを取っているかを確かめるようにしてください。
