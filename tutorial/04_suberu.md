# 第4章 岩まで滑らせる：if を while に変え、町に着いたらクリア

このゲームの主役の動き「岩にぶつかるまで滑る」を作ります。あわせて、町に着いたらクリアになるようにします。

## コードを書きかえる

`move` メソッドを次のように書きかえます。

```python
    def move(self, dx, dy):
        if self.clear:
            return
        # となりが岩でないあいだ、ずっと進む（＝岩まで滑る）
        while not self.is_rock(self.x + dx, self.y + dy):
            self.x += dx
            self.y += dy
            if self.grid[self.y][self.x] == "E":
                self.clear = True  # 町に着いた
                break
```

`__init__` の `pyxel.run` の前に `self.clear = False` を足し、`draw` の最後（プレイヤーを描いたあと）にクリアの表示を足します。

```python
        pyxel.rect(px + 1, py + 1, 6, 6, 9)

        if self.clear:
            pyxel.rect(24, 64, 80, 24, 1)
            pyxel.text(52, 73, "CLEAR!", 10)
```

実行して矢印キーを押すと、プレイヤーが岩の手前まで一気に移動します。町まで滑っていけば「CLEAR!」と出ます。

## while は「条件が成り立つあいだ、くり返す」

`if` は条件が成り立てば1回だけ実行します。`while` は条件が成り立つあいだ、何度でもくり返します。

このコードは「となりが岩でないあいだ、1マス進む」をくり返しています。進むたびに `self.x` と `self.y` が変わるので、「となり」も1マスずつ先にずれていきます。岩の手前まで来ると条件が成り立たなくなり、くり返しが終わります。湖のまわりは岸（`#`）なので、どの向きに滑っても、いつかは必ず止まります。

くり返しは1フレームの中で全部終わってしまうので、画面ではプレイヤーが一瞬で移動したように見えます。途中の動きを見せるアニメーションは第9章で作ります。

## 町に着いたら break で止まる

町 `E` は、岸の列にあります。町のマスに入ったら、その先は湖の外です。そこで、町に着いたらクリアのフラグ `self.clear` を `True` にして、`break` でくり返しを抜けます。`break` は、`while` や `for` のくり返しを途中でやめる命令です。

`self.clear` のように、状態を `True` と `False` で覚えておく変数を **フラグ** と呼びます。クリアしたあとは `move` の最初の `if self.clear: return` で何もしなくなり、プレイヤーは動きません。
