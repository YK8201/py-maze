# PY-MAZE

Pyxel で作った、凍った湖を滑って渡るパズルです。
『レイトン教授と超文明Aの遺産』のナゾ「氷の湖」（ナゾ109・124）を参考にしたルールで、
時間制限や敵はなく、最短手数（PAR）を目指してじっくり考えるゲームにしています。

## ルール

- 湖の向こう岸にある町（赤い屋根の家）まで行けばクリアです
- 氷の上では、上下左右に動くと岩や岸にぶつかるまで滑り続けます
- 水（濃い青）に入ると落ちてしまいます。落ちた手は取り消され、元の場所に戻ります
- もろい氷（ひびの入った青）は乗っても通ってもよいですが、離れると割れて水になります
- 割れた氷のせいで町へ行けなくなったら「STUCK」と表示されます。UNDO で戻ってください
- PAR（最短手数）以内でクリアすると ★ がつきます
- UNDO は何回でも使えます。RESET も UNDO で取り消せます

全20ステージ。ステージ1〜3は岩だけ、4〜8で水、9〜20でもろい氷が出てきます。
クリアした数 +3 ステージ目まで遊べます（難しければ飛ばせます）。

## 操作

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| 移動 | 矢印キー / WASD | スワイプ |
| 1手戻す | Z / U / BackSpace | UNDO ボタン |
| 最初から | R | RESET ボタン |
| ステージ選択 | Esc / M | MENU ボタン |
| 決定 | Enter / Space | タップ |

## 遊び方

### PC

```sh
pip install pyxel
pyxel run game/main.py
```

### スマホ（Web版）

`docs/index.html` が Web 版です。GitHub Pages で `docs/` フォルダを公開すると、
スマホのブラウザで遊べます（Settings → Pages → Branch でブランチと `/docs` を選択）。
GitHub の無料プランでは、Pages を使うにはリポジトリを公開（Public）にする必要があります。

ゲームを変更したら、Web 版を作り直します。

```sh
./tools/build_web.sh
```

## 自分で作ってみたい人へ

[`tutorial/`](tutorial/README.md) に、このゲームを Python を少し書いたことがある中学生が1章ずつ自分の手で作っていくためのテキストがあります（全15章＋付録、各章の完成コード付き）。

## ファイル構成

- `game/main.py` … ゲーム本体（画面・入力・描画）
- `game/core.py` … 氷の湖のルール（ゲームとソルバーで共有）
- `game/levels.py` … ステージデータ
- `game/solver.py` … 最短手数を求めるソルバー。`python game/solver.py` で全ステージの PAR を検証
- `tools/gen_levels.py` … ステージ候補の自動生成ツール（迷いやすさ・落ちる危険・詰みの割合で選ぶ）
- `tools/build_web.sh` … Web 版のビルド
- `tutorial/` … 自分で作るためのテキストと、各章の完成コード

### ステージを増やす

```sh
python tools/gen_levels.py --w 10 --h 10 --water 3 --thin 3 --min-par 10 --max-dead 0.5 --count 3
```

`dead` は詰む局面の割合（既定で 0 のものだけ出力。もろい氷を使うなら `--max-dead` で許す）、
`maze` はでたらめに動いたときの平均手数 ÷ PAR（大きいほど迷いやすい）、
`falls` は水に落ちる手がある局面の割合（大きいほどうっかり落ちやすい）です。
出力された湖を `game/levels.py` に貼り付け、`python game/solver.py` で PAR を確認してください。
湖は手で書いても構いません（`#` 岩・岸、空白 氷、`x` もろい氷、`~` 水、`S` スタート、`E` 町）。
スタートと町は、外周の岸の上に置きます。
